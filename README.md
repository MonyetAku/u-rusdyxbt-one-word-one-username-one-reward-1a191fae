One Word, One Username, One Reward — our entry sends our own make.fun username, one word and nothing else: `monyetsange`. Picked by a 5-candidate tournament judged on the kit's criteria in order (genuine handle first, then smile, memorability, single word, wearability); the other candidates were kerfuffle, bamboozle, wobble and ngakak. The program writes exactly the word, 11 bytes with no trailing newline, to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```
